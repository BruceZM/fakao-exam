# 法考备考系统数据支撑评估

> 评估对象：`fakao-exam` 当前整个法考项目知识库。结论基于 2026-09-04 工作区的数据库、导出文件和审计报告。

## 结论

当前数据可以支撑：

- 内部检索和知识点浏览
- 客观题练习原型
- 已有答案与解析题目的错题复盘
- 以人工复核为前提的主观题批改原型

当前数据不能直接支撑：

- 覆盖完整法考科目的正式备考系统
- 面向用户发布的标准答案和法律结论
- 稳定的主观题自动评分
- 商业化题库或付费产品上线

## 证据

| 能力 | 当前证据 | 判断 |
|---|---:|---|
| 题目规模 | 1117 道；客观 1019，道主观/混合 98 道 | 具备原型规模 |
| 题型结构 | 单选 652、多选 310、判断 57、简答 94、案例分析 4 | 客观题较完整，主观题明显不足 |
| 答案覆盖 | 1041/1117（93.20%） | 总体可练习，但商经知仅 1/73 |
| 解析覆盖 | 984/1117（88.09%） | 可做部分复盘，不能保证全题解析 |
| 知识点 | 1117/1117（100%）已关联 | 可做检索和初步学习路径，仍需人工复核 |
| 法条 | 197/1117（17.64%）有候选关联；246 条候选待核验 | 不能作为稳定法条依据 |
| 主观评分 | 25 条评分点候选，均待专家复核 | 不能直接自动评分或给分 |
| 数据质量 | 完整性验证通过；所有题目仍 `needs_human_review` | 工程链可用，内容尚未最终确认 |
| 来源授权 | 37/37 来源授权状态 unknown | 不能直接用于商业发布 |
| 产品准入 | 0/1117 admitted，1117 blocked | 当前不能进入正式产品层 |

## 分科目风险

- **刑法、民诉法**：答案覆盖完整，解析覆盖较高，可优先做内部练习原型。
- **民法**：题量较大，答案覆盖高，但解析仍有缺口，法条和版本需复核。
- **行政法、刑诉法、理论法**：题量偏小，不能代表完整科目覆盖。
- **商经知**：73 道题中仅 1 道有答案和解析，暂不能支撑该科目备考。
- **主观题**：只有 14 道结构化主观题，且评分点尚未专家确认，暂只能做资料整理和批改实验。

## 建议的产品阶段

### 现在可以做

建立内部 alpha：检索、按科目/题型练习、答案展示、已有解析复盘、知识点聚合和人工审校后台。所有内容显示“研究/审校中”，不作为最终法律结论。

### 上线前必须完成

1. 补齐商经知和其他薄弱科目的题目、答案、解析。
2. 处理 76 道缺答案和 133 道缺解析。
3. 完成答案冲突、题型、法条版本和年份核验。
4. 由法律专业人员复核主观题评分点和案例分析规则。
5. 为每个来源取得可用于产品的授权或改用自有原创内容。
6. 使来源审校、法律版本和质量状态达到产品准入条件。

## 最终判断

**可以支撑一个内部知识库驱动的备考原型；不能支撑完整、可靠、可商业发布的法考备考系统。** 当前最大短板不是检索或数据库技术，而是科目覆盖不均、答案/解析缺口、法条与评分规则未完成核验，以及来源授权未解决。
