# 法考练习新版：本地验收

本次修改在 fakao-exam 内完成，待本地体验确认后再发布。

## 启动与体验

```sh
python3 -m uvicorn server.main:app --host 127.0.0.1 --port 8876
```

访问 http://127.0.0.1:8876，使用现有访问口令。服务读取本机 deploy.txt 或环境变量；口令不会作为浏览器记录键名。未配置时默认口令为 1234。记录仅在当前浏览器保存，刷新后重新验证口令并选择“继续上次练习”。

- 客观题：阶段选客观题 → 科目 → 选择选项 → 提交 → 错题重练。多选必须与参考答案集合一致。
- 主观题：阶段选主观题 → 科目 → 输入作答 → 参考试评或分析建议。草稿自动保存。
- 查看参考答案不增加完成次数。主观题可手动标记待巩固；完整评分点试评未全命中的题自动进入待巩固。
- 历史作答与反馈可以展开查看。用户、阶段、科目通过独立存储键隔离。

## 数据与评分

当前 bundle 共 1034 题：857 道可判分客观题、79 道仅浏览客观资料、98 道主观训练资料。
6 道主观题的显式评分点能对应原文且分值之和匹配题干总分，可参考试评；其余题只给建议。
canonical 映射使用明确映射表，不采用模糊题号匹配。未明确题干总分、评分点原文不匹配或分值不完整时，不提供分数。

完整性检查不是法律专家审定。内容和评分点审校状态仍保留。

## 验证结果

- 7 项 API/评分规则回归测试通过：鉴权、用户隔离、答案隐藏、选择判题、异常资料隔离、映射与评分完整性、原文证据、流式成功和失败。
- 浏览器验证：漏选判错、订正后退出错题、查看答案不计次数、用户切换隔离、原用户记录恢复、刷新草稿恢复。
- 模拟流式连接中断：原答案保留且不计完成；恢复真实服务后重试成功。
- 真实 AI：完整评分点题返回 2/2 参考分；无评分点题 score 和 max_score 均为空；浏览器真实主观题反馈完成。
- 390px 手机页面单栏、无横向溢出；桌面主观题双栏；浏览器无捕获的页面错误。

发布前需要用户确认本地体验。当前改动尚未推送 GitHub 或 ModelScope。
