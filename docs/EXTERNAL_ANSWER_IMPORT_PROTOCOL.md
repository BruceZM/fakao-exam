# 外部答案来源导入规范

本规范适用于从公开网页、作者账号或用户补充的答案版中获取法考答案。外部链接只代表候选来源，不代表内容已核验，也不代表可用于商业产品。

## 导入前

1. 记录来源 URL、发布者、抓取时间和授权状态。
2. 保存原始页面、图片或 PDF 的本地副本，并记录文件哈希。
3. 确认题号、题干和题型与现有 `question_id` 对应；禁止仅按文件顺序覆盖。

## 导入字段

- 原始答案写入 `answer_raw`，规范化字母写入 `answer`。
- 记录 `answer_source_id`、来源文件和 `answer_review_status`。
- 解析正文单独写入 `explanation`，不得把答案页脚、宣传语或章节标题写入答案字段。
- 每批修改前生成 `data/questions/backups/` 备份，并在 `data/questions/lineage/` 记录题号、来源、时间和变更原因。

## 复核门槛

- 单选题只能有一个答案字母；多选/不定项题必须与扫描题型说明一致。
- 题干相似度不足或存在多个候选匹配时，标记人工复核，不自动合并。
- 回填后运行 `python3 tools/rebuild_kb.py --project-root .`、`python3 tools/kb_doctor.py --root .` 和冒烟测试。
- 授权状态未知时，内容可以保留在内部审校区，但不得进入产品准入数据。
